# 🤝 Como Contribuir com o Bootstrap4Noobs

Primeiro: obrigado por considerar contribuir. Projeto 4noobs só existe de pé por causa de gente que doa tempo pra ensinar de graça. 🙌

## Formas de contribuir

- **Corrigir conteúdo técnico** — o Bootstrap evolui entre versões, e erros acontecem. Abra uma issue ou PR direto.
- **Melhorar analogias e didática** — se você leu um módulo e achou uma explicação confusa, sua sugestão de reescrita vale ouro.
- **Preencher módulos em construção 🚧** — veja a pasta `modulos/` e escolha um que ainda esteja como rascunho.
- **Adicionar exemplos de código** — quanto mais código funcional e comentado, melhor.
- **Corrigir português e clareza** — inclusão vem em primeiro lugar, texto ruim afasta gente.

## Passo a passo

1. Dê um fork no repositório.
2. Crie uma branch descritiva: `git checkout -b modulo-3-navbar`
3. Faça suas alterações seguindo o [Módulo 1](modulos/01-o-que-e-bootstrap-e-mentalidade/README.md) como referência de estilo.
4. Teste todo exemplo de código antes de commitar — copie e cole no navegador, veja se funciona.
5. Abra um Pull Request explicando o que mudou e por quê.

## Regras de ouro (não negociáveis)

- ❌ Sem plágio de conteúdo de curso pago ou de outros sites sem crédito.
- ✅ Todo exemplo de código deve ser testado e funcional.
- ✅ Sempre com analogias, exemplos e tom acessível para quem está no zero absoluto.
- ✅ Priorize sempre a versão estável mais recente do Bootstrap (atualmente a linha 5.3.x).

Dúvidas? Abra uma issue com a tag `duvida-contribuicao`.
