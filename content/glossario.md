Termos técnicos, explicados sem economês. Ordem alfabética.

| Termo | Explicação simples |
|---|---|
| **Breakpoint** | Ponto de largura de tela onde o layout muda de comportamento (ex: `md` = tablets) |
| **CDN** | Servidor externo de onde você "importa" o Bootstrap sem precisar baixar arquivos |
| **Classe utilitária** | Classe CSS pronta que faz uma coisa pequena e específica (ex: `mt-3` = margem no topo) |
| **Container** | Elemento que centraliza e limita a largura do conteúdo da página |
| **Grid System** | Sistema de 12 colunas que organiza o layout de forma responsiva |
| **Gutter** | Espaçamento (calha) entre as colunas do grid |
| **Mobile-first** | Filosofia de projetar primeiro para telas pequenas e depois adaptar para telas grandes |
| **Responsivo** | Layout que se adapta automaticamente ao tamanho da tela do dispositivo |
| **Sass** | Uma extensão do CSS que permite variáveis, funções e customização avançada do Bootstrap |
| **data-bs-\*** | Atributos HTML que ativam comportamento de JavaScript do Bootstrap sem escrever código (ex: abrir modal) |

> Sentiu falta de algum termo? Abra uma issue ou PR — veja o [CONTRIBUTING.md](../CONTRIBUTING.md).
