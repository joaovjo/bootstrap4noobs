## O que este módulo vai cobrir

- Os blocos de montar mais usados do Bootstrap;
- Navbar: do desktop ao menu hambúrguer no celular;
- Cards, Botões, Formulários, Modals e Alerts;
- Como o JavaScript do Bootstrap funciona (sem jQuery, via data attributes);
- Erros mais comuns ao usar componentes prontos.

## Estrutura sugerida

1. Navbar: anatomia, branding, links e o botão toggler (hambúrguer);
2. Cards: anatomia (header, body, footer, imagem);
3. Forms: inputs, labels, validação visual (`is-valid`/`is-invalid`);
4. Modals: como abrir/fechar via `data-bs-*` sem escrever JavaScript;
5. Alerts: feedback visual para o usuário;
6. Mão na Massa: montar uma página de login com navbar, form e alerta de erro;
7. Checklist de saída.
