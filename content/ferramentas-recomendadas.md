# Ferramentas Recomendadas

[« Glossário](glossario.md) — [Índice](../README.md#roadmap)

Tudo nesta lista é gratuito e útil para praticar Bootstrap no dia a dia.

## Para começar rápido (sem instalar nada)

- **CDN oficial do Bootstrap** — `https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/...` (veja o Módulo 1).
- **CodePen / JSFiddle** — testar código HTML/CSS/JS direto no navegador, sem configurar ambiente.

## Documentação e referência

- **Documentação oficial do Bootstrap** — a fonte mais confiável, sempre atualizada com a versão mais recente.
- **Bootstrap Icons** — biblioteca de ícones gratuita e oficial do próprio time do Bootstrap.

## Para testar responsividade e acessibilidade

- **DevTools do navegador (modo responsivo)** — F12 → ícone de celular/tablet.
- **Google Lighthouse** — auditoria de performance, acessibilidade e boas práticas, já embutida no Chrome DevTools.
- **axe DevTools** — extensão gratuita focada em acessibilidade.

## Para estudar código pronto

- **Start Bootstrap** — templates e temas gratuitos e open-source para desmontar e estudar.
- **Bootstrap Examples (site oficial)** — exemplos oficiais mantidos pelo próprio time do framework.

> **Dica:** nunca copie um template inteiro sem entender o que cada classe faz. O objetivo aqui é aprender, não só entregar bonito.
