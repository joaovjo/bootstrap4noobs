## O que este módulo vai cobrir

- Classes utilitárias: spacing (`m-*`, `p-*`), flexbox (`d-flex`, `justify-content-*`), cores e texto;
- Como fugir da "cara de Bootstrap" (o visual genérico que todo mundo reconhece);
- Customização via variáveis CSS (Bootstrap 5) e via Sass;
- Criando um tema próprio.

## Estrutura sugerida

1. Tour pelas classes utilitárias mais usadas no dia a dia;
2. Por que todo site "parece Bootstrap" e como evitar isso;
3. Customizando cores e fontes via variáveis CSS;
4. Customização avançada via Sass (`$primary`, `$font-family-base`, etc.);
5. Mão na Massa: pegar a página do Módulo 3 e trocar completamente a paleta de cores;
6. Checklist de saída.
