## O que este módulo vai cobrir

- Testando responsividade de verdade (DevTools, dispositivos reais, breakpoints intermediários);
- Acessibilidade: atributos ARIA que o Bootstrap já espera que você use;
- Erros comuns de iniciante (excesso de `!important`, ignorar contraste de cor, esquecer o `alt` de imagem);
- Performance: importando só o CSS que você usa.

## Estrutura sugerida

1. Checklist de testes de responsividade;
2. Acessibilidade não é opcional: ARIA labels em componentes interativos;
3. Contraste de cores e leitura por leitor de tela;
4. Os 5 erros mais comuns de quem está aprendendo Bootstrap;
5. Mão na Massa: auditar uma página com ferramentas de acessibilidade gratuitas (Lighthouse, axe);
6. Checklist de saída.
